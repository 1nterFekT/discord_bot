# How to install

1. Rename `.env.example` to `.env` and configure it
2. Use Python interpreter 3.13 (actually you can use different one, but we used this one)
3. Write `python -m venv venv` in console
4. Write `venv\Scripts\activate` in console
5. Select Python interpreter from venv if it not selected yet
6. Write `pip install -r requirements.txt` in console
7. Congratulations! Now you can use `py bot.py` to run your bot
